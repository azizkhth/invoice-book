# 🧾 دفتر الفواتير — Invoice Book

تطبيق ويب بسيط **لتسجيل الفواتير**: اسم الفاتورة، رقمها، تاريخها، ومبلغها — مع **لوحة معلومات**، ودعم كامل للعربية **RTL**، و**وضع ليلي/نهاري**، وحسابات مستخدمين ببيانات **معزولة تمامًا** عن الآخرين.

> مشروع "الورشة الثالثة": مشروع يعتمد على قواعد البيانات — قاعدة محلية (localStorage) لكل مستخدم + دعم اختياري لـ **Supabase Database مع تفعيل RLS**.

---

## ✨ الميزات

- 🧾 **تسجيل فاتورة بأربعة حقول**: الاسم، الرقم، **تاريخ الفاتورة**، المبلغ
- ✏️ تعديل وحذف مع نافذة تأكيد، وبحث فوري بالاسم أو الرقم، ومنع تكرار رقم الفاتورة
- 📊 **لوحة معلومات**: عدد الفواتير، إجمالي المبالغ، أعلى فاتورة، فواتير هذا الشهر، ومخطط أعمدة لتباين المبالغ في آخر 6 أشهر
- 🔐 **تسجيل دخول وإنشاء حساب** (بريد إلكتروني + كلمة مرور)، وبيانات كل مستخدم في **مفتاح تخزين مستقل** `ib_invoices_<userId>`
- 🌙☀️ **وضع ليلي/نهاري** مع حفظ الاختيار
- 📱 تصميم متجاوب للجوال، ودعم **RTL كامل** بخط Cairo
- 🚀 زر **"تجربة سريعة"** يفتح حسابًا تجريبيًا جاهزًا ببيانات استعراض

## 🗄️ قاعدة البيانات

### 1) الوضع المحلي (الافتراضي) — localStorage
| المفتاح | المحتوى |
|---|---|
| `ib_users` | سجل المستخدمين (كلمة المرور تُخزَّن هاش SHA-256) |
| `ib_session` | معرّف المستخدم الحالي |
| `ib_invoices_<userId>` | فواتير كل مستخدم — **معزولة لكل مستخدم** |

> ⚠️ ملاحظة تقنية: المصادقة عبر localStorage مفيدة تعليميًا وتفي بفكرة "قاعدة بيانات محلية لكل مستخدم"، لكنها ليست بديلاً عن خدمات مصادقة حقيقية في الإنتاج.

### 2) وضع Supabase مع RLS (اختياري — يغطي اشتراط الورشة)
1. أنشئ مشروعًا مجانيًا على [supabase.com](https://supabase.com).
2. من **SQL Editor** نفّذ الملف [`supabase/schema.sql`](supabase/schema.sql) — ينشئ جدول `invoices` ويفعّل **RLS** بسياسات `auth.uid() = user_id` بحيث يرى كل مستخدم بياناته هو فقط مهما استُخدم من أدوات.
3. (للتجربة السريعة) من **Authentication → Providers → Email** عطّل خيار "Confirm email".
4. في الموقع: اضغط **⚙️ ربط Supabase (اختياري)** في شاشة الدخول، والصق **Project URL** ومفتاح **anon** ثم "حفظ وربط".
5. بعدها تُحفظ الفواتير في Supabase ويظهر شعار **🔌 Supabase + RLS** في الواجهة.

## 🚀 النشر على GitHub Pages

1. ارفع هذه الملفات إلى مستودع GitHub جديد (مثال باسم `invoice-book`):

```bash
git init -b main
git add .
git commit -m "Invoice Book: RTL Arabic invoicing app (localStorage + Supabase RLS)"
git remote add origin https://github.com/<اسم-مستخدمك>/invoice-book.git
git push -u origin main
```

2. من المستودع: **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / المجلد: **/(root)** ← ثم **Save**
3. بعد دقيقة تقريبًا يصبح الموقع متاحًا على:
   `https://<اسم-مستخدمك>.github.io/invoice-book/`
